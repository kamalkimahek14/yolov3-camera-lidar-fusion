# Third-party code

The MIT License in [LICENSE](LICENSE) covers all code in this repository: the original 2021 thesis scripts and the YOLO v3 helper functions in `detection/yolov3/`, which I wrote in 2026 as an independent implementation of YOLO v3 (Redmon & Farhadi, 2018). The scripts also call code from other authors. This repository does not include that code; get it from the sources below and put it on the MATLAB path.

## Not included: get these from their source

| Needed by | Files | Where to get them | License |
|---|---|---|---|
| `calibration/camera_lidar_calibration.m`, `calibration/extrinsic_from_corners.m` | `helperShowError.m` (error plots; my working copy had edited titles and fields) | MathWorks example *Lidar and Camera Calibration* (Lidar Toolbox documentation) | MathWorks license |
| `calibration/capture_calibration_frames.m`, `lidar/stream_pointcloud_roi.m`, `fusion/realtime_fusion.m` | `+realsense` package and `librealsense_mex` | Intel RealSense SDK 2.0, MATLAB wrapper: <https://github.com/IntelRealSense/librealsense/tree/master/wrappers/matlab> | Apache License 2.0 |

The streaming set-up lines in those three RealSense scripts (pipeline, colorizer, point cloud, and discarding the first frames) follow the usage examples of that wrapper, Copyright Intel Corporation, licensed under the [Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0).

`fusion/realtime_fusion.m` also calls `bboxCameraToLidar`, a Lidar Toolbox function available from R2021a.

## Left out of this repository

MathWorks example code from my 2021 working folders is not redistributed here, because example code that ships with MATLAB is covered by the MathWorks license. `detection/yolov3/` replaces the YOLO v3 example helpers that the thesis scripts called. These other example files are left out; the final pipeline does not call them: `helperShowImageCorners.m`, `helperShowLidarCorners.m`, `helperFuseLidarCamera.m` (Lidar and Camera Calibration example), `fitRectangle3D.m`, `getLidarBbox.m`, `helperLidarCameraObjectsDisplay.m` (Lidar Toolbox), `helperDetect.m`, `helperLidarTrackingAlgorithm.m`, `HelperBoundingBoxDetector.m` (Sensor Fusion and Automated Driving examples), and the example scripts `yolo_v3.m` and `anchor_estimation.m`, which run on the MathWorks vehicle dataset.
